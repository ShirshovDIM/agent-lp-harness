What the loop already found

  • Tick-grid geometry dominates re-range economics: on a ~22%-step grid a "small-swap" re-range is geometrically impossible — it equals the full swap on all 113 starts.
  • On a fine grid, no-swap modes win medians but cost p90 = 5–12 rewardless days per start.
  • Fee sensitivity is second-order: 0.05% → 0.6% moves median differences by < 1 USD per 150 USD.

Report format spec

  • Window (hours, price range, regime caveat)
  • Method (position, widths, costs incl. stress variants)
  • Statistics (medians p10/p90, tails P(<−5%)/P(<−10%), 113 seeded starts)
  • Calibration vs a live position (or an explicit "no live position yet")
  • Caveats — stated, not hidden
