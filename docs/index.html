04 · what the loop already found

Three results from measured windows

~22 %

Tick-grid geometry dominates

On a ~22 %-step grid (CL2000 = ×1.2214) a small-swap re-range is geometrically impossible: mode B2 equals the full swap on all 113 starts — difference 0.00 USD on both horizons.

5–12 days

No-swap modes cost rewardless days

On the fine CL50 grid (~0.5 % step) no-swap modes win medians, but their p90 time without rewards is 5.08–12.04 days per start (B1, exit starts, 14/30 d).

< 1 USD

Fee sensitivity is second-order

Raising the swap-fee stress from 0.05 % to 0.6 % moves the median differences by < 1 USD per 150 USD position.
